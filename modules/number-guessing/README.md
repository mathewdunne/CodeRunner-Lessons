# Number Guessing Game

Work in `src/Main.java`. Run this lesson with the editor Run button.

## Steps

1. Use `Random` to choose a secret number from 1 to 10.
2. Use a `Scanner` to read the user's guess.
3. Print `higher`, `lower`, or `correct`.

## Bonus

- Increase the range of possible numbers.
- Keep score.
- Add a maximum number of guesses and print win/loss at the end.
