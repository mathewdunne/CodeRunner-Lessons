# Kitbot Controls

This project starts from the AdvantageKit kitbot template with drive speed slowed down.

## Steps

1. Add a fast-mode button that doubles drive speed while held.
2. Add a beyblade-mode button that spins the robot in place as fast as possible while held.
3. Start beyblade mode as a command that requires the drive subsystem.
4. After it works, try to keep translation control working while the robot spins.

## Bonus

- Add a button that toggles between blue-alliance and red-alliance driving modes.
- Mirror the controls when red-alliance mode is active.
