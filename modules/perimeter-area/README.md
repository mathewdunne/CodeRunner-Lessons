# Perimeter and Area

Work in `src/Main.java`. Run this lesson with the editor Run button.

## Steps

1. Ask the user for a rectangle length and width.
2. Calculate and print the rectangle perimeter and area.
3. Add a shape menu: `1` rectangle, `2` triangle, `3` circle.
4. Ask the user for the measurements that shape needs (radius, or length and width, or base and height) and print its perimeter and area.

## Bonus

- Handle invalid input without crashing.
- Add a cube and calculate volume.
- Add another shape.
